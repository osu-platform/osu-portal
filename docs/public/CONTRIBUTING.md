# Разработка

Перед сдачей изменений нужны типы, границы модулей, unit-тесты, обе сборки и проверка UI в браузере. Проверяйте загрузку, пустое состояние, ошибку API, результат изменения после ответа сервера.

Приватные модули держите во внешних проектах. В фикстурах используйте синтетические данные, в media — только ресурсы с известным происхождением. Новая зависимость требует повторного лицензионного аудита и notices. Создание модуля описано в MODULE_GUIDE.md. Подготовка публичного дерева не публикует репозитории и не отправляет ветки.
