# Assets

The three minimal vector-animation JSON files in shared/assets were authored for this project during public preparation. Previous untraced animations and .lottie were removed. The WASM is imported from the pinned @lottiefiles/dotlottie-web distribution and is covered by its supplied licenses. Story media and the MAX demo icon use an original synthetic SVG. Spoiler uses an original CSS pattern. The untraced Storybook bitmap logo was removed. Existing SVG icons in shared UI retain the Telegram UI/MIT upstream notices.
