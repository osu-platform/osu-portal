# Выбор лицензии

Рекомендуется Apache-2.0 для собственного кода. Пользователь подтвердил авторство: его код и код друга; авторы проекта — Дмитрий Колядин и Василий Шевлюк (OSU Platform / DAVG). Подготовка сохраняет текущую корневую LICENSE до окончательного решения авторов. Полный предложенный текст: licenses/Apache-2.0.proposed.txt. Сторонние произведения не перелицензируются.

Из предоставленных условий конкурса: запрещены GPL-подобные лицензии и запрет коммерческого использования. Apache-2.0 разрешает коммерческое использование, модификацию и распространение, содержит патентное разрешение, не требует открытия производных работ. Альтернатива MIT проще, но не содержит столь же явного патентного разрешения. Полного регламента конкретного конкурса нет; соответствие неизвестным пунктам не утверждается.

Проверены активные зафиксированные npm-зависимости и явно заимствованный UI-код. MIT, ISC, BSD, Apache, 0BSD, CC0/Unlicense сохраняют свои условия. У type-fest выбирается MIT из `(MIT OR CC0-1.0)`. Python-2.0 у argparse — разрешительная, не GPL; её текст сохранён. CC-BY-4.0 у справочных данных требует атрибуции, сохранённой в DEPENDENCY_NOTICES.md. Неиспользуемый Sentry build plugin с FSL CLI и addon с axe-core/MPL удалены из поставляемого набора. В активном lock нет обязательных GPL/AGPL/LGPL/MPL/FSL/NonCommercial лицензий.

Вендорный UI-kit и фрагменты VKUI, Material UI, React Children Utilities сохраняют MIT: packages/shared/ui/LICENSE, licenses/\*.txt, THIRD_PARTY_NOTICES.md. Изменения UI-kit описаны, неподтверждённые media заменены/удалены. WASM импортируется из лицензированной npm-поставки. Товарные знаки сторонних сервисов авторами портала не лицензируются.

Источники: https://www.apache.org/licenses/LICENSE-2.0.html (§2–4), https://www.apache.org/legal/resolved, исходные upstream LICENSE из THIRD_PARTY_NOTICES.md. Политика ASF — справочная проверка совместимости, не регламент конкурса.

Для релиза сохранить LICENSE, NOTICE, THIRD_PARTY_NOTICES.md, DEPENDENCY_NOTICES.md и licenses с исходниками и артефактами. Аудит: `node scripts/license-audit.mjs docs/dependency-licenses.json --notices` после frozen install. Новые зависимости требуют повторной проверки, включая транзитивные компоненты.
